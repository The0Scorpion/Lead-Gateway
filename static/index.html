Endpoint Details

POST https://lead_gateway/api/v1/lead/{LEAD_KEY}

The agentic backend accepts any flat JSON structure. It will autonomously normalize keys (e.g., matching `contact_cell` to `phone`) and format them correctly for the destination CRM.

cURL Example 
curl -X POST "https://lead_gateway/api/v1/lead/key_123456" \
-H "Content-Type: application/json" \
-d '{
  "name": "Jane Doe",
  "phone": "555-987-6543",
  "notes": "Highly motivated."
}'
